# สมุดคะแนนนักเรียน

เว็บไซต์สำหรับครู ใช้กรอกและเก็บคะแนนนักเรียน และดูคะแนนเป็นรายบุคคล

เปิดใช้งาน: https://ftfluk29050-oss.github.io/student-scores/

## หน้าในเว็บ

| หน้า | ใช้ทำอะไร |
| --- | --- |
| หน้าแรก | การ์ดทางเข้า 3 ใบ: กรอกคะแนน ข้อมูลนักเรียน เพิ่มวิชา |
| กรอกคะแนน | เลือกวิชาและห้อง แล้วกรอกคะแนนในตาราง รวมคะแนนและตัดเกรดให้อัตโนมัติ |
| นักเรียน | รายชื่อแต่ละห้อง กดชื่อเพื่อเปิดข้อมูลรายบุคคล (คะแนนแต่ละช่อง เทียบค่าเฉลี่ยห้อง งานที่ค้าง บันทึกของครู พิมพ์ได้) |
| วิชาและข้อมูล | เพิ่ม/แก้ไขวิชา สำรองและกู้คืนข้อมูล |

## เริ่มใช้งาน

1. กด **เพิ่มวิชา** ใส่ชื่อวิชา เลือกห้องที่สอน
2. กด **เพิ่มช่องคะแนน** เพื่อสร้างช่อง เช่น ใบงานที่ 1 เต็ม 10 (กดชื่อช่องที่หัวตารางเพื่อแก้ไข ย้าย หรือลบ)
3. กรอกคะแนน กด Enter เพื่อลงไปคนถัดไป วางคะแนนที่คัดลอกจาก Excel ได้ทั้งคอลัมน์
4. กด **สำรองข้อมูลเป็นไฟล์** ที่หน้า “วิชาและข้อมูล” ทุกครั้งหลังกรอกคะแนน

## ติดตั้งเป็นแอป

เว็บนี้ติดตั้งลงมือถือหรือคอมพิวเตอร์ได้ และเปิดได้แม้ไม่มีอินเทอร์เน็ต

- Android (Chrome): เมนู ⋮ แล้วเลือก “ติดตั้งแอป” หรือ “เพิ่มลงในหน้าจอหลัก”
- iPhone/iPad (Safari): ปุ่มแชร์ แล้วเลือก “เพิ่มไปยังหน้าจอโฮม”
- คอมพิวเตอร์ (Chrome/Edge): ไอคอนติดตั้งที่ขวาสุดของช่องที่อยู่เว็บ หรือปุ่ม “ติดตั้งแอป” ในหน้า “วิชาและข้อมูล”

## เปิดใช้ระบบล็อกอินและซิงก์ข้ามเครื่อง (Firebase)

ถ้ายังไม่ได้ตั้งค่า เว็บจะเก็บข้อมูลในเครื่องและไม่มีหน้าล็อกอิน เมื่อตั้งค่าตามนี้แล้วจะต้องล็อกอินก่อนใช้
และคะแนน รูป บันทึกของครู จะเก็บบนคลาวด์ในบัญชีของคุณครู เปิดจากเครื่องไหนก็เห็นข้อมูลเดียวกัน

1. **สร้างโปรเจกต์** เปิด https://console.firebase.google.com กด “Create a project” ตั้งชื่อ เช่น `student-scores` (ปิด Google Analytics ได้)
2. **เปิดการล็อกอิน** เมนู Build → Authentication → Get started → แท็บ Sign-in method → เลือก **Email/Password** → Enable → Save
3. **สร้างบัญชีครู** กด “สมัครใช้งาน” ที่หน้าล็อกอินของเว็บ (หรือสร้างในแท็บ Users → Add user ของ Firebase ก็ได้)
4. **อนุญาตโดเมนของเว็บ** Authentication → Settings → Authorized domains → Add domain → `ftfluk29050-oss.github.io`
5. **สร้างฐานข้อมูล** เมนู Build → Firestore Database → Create database → เลือกตำแหน่ง `asia-southeast1 (Singapore)` → Start in **production mode**
6. **ตั้งกฎความปลอดภัย** แท็บ Rules ของ Firestore ลบของเดิม วางข้อความนี้ แล้วกด Publish

   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /users/{uid}/{document=**} {
         allow read, write: if request.auth != null && request.auth.uid == uid;
       }
     }
   }
   ```

   กฎนี้ทำให้แต่ละบัญชีอ่านและเขียนได้เฉพาะข้อมูลของตัวเอง คนที่ไม่ได้ล็อกอินอ่านไม่ได้
7. **นำค่าเชื่อมต่อมาใส่เว็บ** ไอคอนเฟือง → Project settings → Your apps → กดไอคอน `</>` (Web) → ตั้งชื่อแอป → Register app
   แล้วคัดลอกค่า `firebaseConfig` ไปวางในไฟล์ `js/firebase-config.js` แทน `null`

ครั้งแรกที่ล็อกอิน ถ้าเครื่องนั้นมีข้อมูลที่เคยกรอกไว้ในเครื่อง ระบบจะย้ายขึ้นคลาวด์ให้

## ข้อมูลเก็บที่ไหน

- **ยังไม่ได้เปิดใช้ล็อกอิน:** คะแนน รูปนักเรียน และบันทึกของครู เก็บในเบราว์เซอร์ของเครื่องที่ใช้กรอกเท่านั้น
  ถ้าจะย้ายเครื่อง ให้สำรองเป็นไฟล์แล้วกู้คืนในเครื่องใหม่
- **เปิดใช้ล็อกอินแล้ว:** ข้อมูลเก็บใน Firestore ของโปรเจกต์ Firebase ของคุณครู ใต้บัญชีที่ล็อกอิน และมีสำเนาในเครื่องเพื่อใช้ตอนออฟไลน์
- **รายชื่อนักเรียน** อยู่ในไฟล์ `data/roster.js` ซึ่งเป็นส่วนหนึ่งของเว็บ ผู้ที่มีลิงก์เปิดดูได้แม้ไม่ได้ล็อกอิน

## โครงสร้างไฟล์

```
index.html        โครงหน้าเว็บ
css/style.css     หน้าตา
js/app.js         การทำงานทั้งหมด
js/cloud.js       การล็อกอินและซิงก์กับ Firebase
js/vendor/paper-warp.js  พื้นหลังเคลื่อนไหวของการ์ดหน้าแรก (Paper Shaders, Apache-2.0)
js/firebase-config.js  ค่าเชื่อมต่อ Firebase (null = ไม่ใช้ล็อกอิน)
sw.js, manifest.webmanifest  ทำให้ติดตั้งเป็นแอปและใช้ออฟไลน์ได้
data/roster.js    รายชื่อนักเรียนแต่ละห้อง (แก้ไขไฟล์นี้เมื่อมีนักเรียนย้ายเข้า/ออก)
```

เกณฑ์ตัดเกรด: 80 ขึ้นไป = 4, 75 = 3.5, 70 = 3, 65 = 2.5, 60 = 2, 55 = 1.5, 50 = 1, ต่ำกว่า 50 = 0
(แก้ได้ที่ตัวแปร `GRADES` ใน `js/app.js`)
