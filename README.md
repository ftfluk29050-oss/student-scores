# สมุดคะแนนนักเรียน

เว็บไซต์สำหรับครู ใช้กรอกและเก็บคะแนนนักเรียน และดูคะแนนเป็นรายบุคคล

เปิดใช้งาน: https://ftfluk29050-oss.github.io/student-scores/

## หน้าในเว็บ

| หน้า | ใช้ทำอะไร |
| --- | --- |
| กรอกคะแนน | เลือกวิชาและห้อง แล้วกรอกคะแนนในตาราง รวมคะแนนและตัดเกรดให้อัตโนมัติ |
| นักเรียน | รายชื่อแต่ละห้อง กดชื่อเพื่อเปิดข้อมูลรายบุคคล (คะแนนแต่ละช่อง เทียบค่าเฉลี่ยห้อง งานที่ค้าง บันทึกของครู พิมพ์ได้) |
| วิชาและข้อมูล | เพิ่ม/แก้ไขวิชา สำรองและกู้คืนข้อมูล |

## เริ่มใช้งาน

1. กด **เพิ่มวิชา** ใส่ชื่อวิชา เลือกห้องที่สอน
2. กด **เพิ่มช่องคะแนน** เพื่อสร้างช่อง เช่น ใบงานที่ 1 เต็ม 10 (กดชื่อช่องที่หัวตารางเพื่อแก้ไข ย้าย หรือลบ)
3. กรอกคะแนน กด Enter เพื่อลงไปคนถัดไป วางคะแนนที่คัดลอกจาก Excel ได้ทั้งคอลัมน์
4. กด **สำรองข้อมูลเป็นไฟล์** ที่หน้า “วิชาและข้อมูล” ทุกครั้งหลังกรอกคะแนน

## ข้อมูลเก็บที่ไหน

- **คะแนนและบันทึกของครู** เก็บในเบราว์เซอร์ของเครื่องที่ใช้กรอกเท่านั้น ไม่ถูกส่งขึ้นอินเทอร์เน็ต
  คนอื่นที่เปิดเว็บนี้จะไม่เห็นคะแนน ถ้าจะย้ายเครื่อง ให้สำรองเป็นไฟล์แล้วกู้คืนในเครื่องใหม่
- **รายชื่อนักเรียน** อยู่ในไฟล์ `data/roster.js` ซึ่งเป็นส่วนหนึ่งของเว็บ ผู้ที่มีลิงก์เปิดดูได้

## โครงสร้างไฟล์

```
index.html        โครงหน้าเว็บ
css/style.css     หน้าตา
js/app.js         การทำงานทั้งหมด
data/roster.js    รายชื่อนักเรียนแต่ละห้อง (แก้ไขไฟล์นี้เมื่อมีนักเรียนย้ายเข้า/ออก)
```

เกณฑ์ตัดเกรด: 80 ขึ้นไป = 4, 75 = 3.5, 70 = 3, 65 = 2.5, 60 = 2, 55 = 1.5, 50 = 1, ต่ำกว่า 50 = 0
(แก้ได้ที่ตัวแปร `GRADES` ใน `js/app.js`)
